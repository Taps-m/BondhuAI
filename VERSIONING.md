# Bondhu AI release versioning

Every release must have a version number displayed as `V X.Y.Z`.

- **X — Major:** substantial product changes or incompatible changes.
- **Y — Minor:** new features compatible with the current major release.
- **Z — Patch:** bug fixes and small improvements.

Incrementing X resets Y and Z to zero. Incrementing Y resets Z to zero.
For example: `V 1.0.0`, `V 1.1.0`, `V 1.1.1`, `V 2.0.0`.

Assign versions when preparing a release, not for every individual edit.
Record the version and its changes in release notes. Do not label a release
as published until it has actually been released.
